# Indian Weather Pre-Predection

## 🌤 Overview

**NASA India Weather** is a modern React-based web application that provides **weather analytics for all Indian states and union territories**.
The application offers **current weather conditions, 24-hour trends, 7-day forecasts, wind speed analysis, and precipitation probabilities**. It also includes **user authentication**, allowing users to save their preferred states for quick access.

---

## 🚀 Features

* **User Authentication**: Sign up and log in with email/password. Demo account: `demo@nasa.com / demo123`.
* **State Selection**: Select any of the 36 Indian states or union territories to view weather data.
* **Weather Analytics**:

  * Current temperature, humidity, wind speed, visibility, and air quality index (AQI).
  * Condition labels such as Very Good, Good, Moderate, Poor.
* **Forecasts and Trends**:

  * 24-hour temperature and “feels like” trend (Area Chart).
  * 7-day forecast with temperature and humidity (Line Chart).
  * Wind speed and precipitation probability (Bar Charts).
* **Saved States**: Users can save recently searched states for quick access.
* **Responsive Design**: Works on mobile, tablet, and desktop.
* **Modern UI**: Built using Tailwind CSS and Lucide icons for a visually appealing experience.

## ⚙️ Installation

1. **Clone the repository**:

```bash
git clone https://github.com/LakshTrivedi/Indian_Weather_Pre-Predection.git
cd Indian_Weather_Pre-Predection
```

2. **Install dependencies**:

```bash
npm install
```

3. **Start the development server**:

```bash
npm start
```

The app will be available at `http://localhost:3000`.

---

## 🧑‍💻 Usage

* **Login**: Use the demo account or sign up for a new account.
* **Select State**: Pick a state from the dropdown to fetch weather data.
* **View Analytics**: Explore current conditions, hourly trends, 7-day forecast, wind and precipitation charts.
* **Save States**: Your recent searches are saved for easy future access.
* **Logout**: Click the logout button to switch users.

---

## 📊 Technology Stack

* **Frontend**: React, Tailwind CSS
* **Charts & Visualization**: Recharts
* **Icons**: Lucide React
* **State Management**: React Hooks (`useState`)
